# 🛒 E-Commerce Customer Demographics Dashboard

Dashboard ini dibuat menggunakan Streamlit untuk memvisualisasikan data demografi pelanggan E-Commerce di Brazil, termasuk persebaran pelanggan berdasarkan kota, negara bagian, dan region makro.

## Setup Environment - Anaconda
```bash
conda create --name main-ds python=3.11
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal
```bash
cd proyek_analisis_data
pipenv install
pipenv shell
pip install -r requirements.txt
```

## Run Streamlit App
```bash
cd dashboard
streamlit run dashboard/dashboard.py
```
